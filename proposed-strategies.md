# Proposed strategies (from your library)

Priority order for building systems — live scanner already implements 1–3.

## Live / market-structure (do these first)

1. **Line shopping** — always take best number across books (*Sharper*, Miller/Davidow).
2. **Soft vs sharp gap** — soft books lagging Pinnacle/exchange (*Sharper*, Buchdahl).
3. **Cross-book arbitrage** — rare locked prices (*Vlastakis*, Sharper middles/scalps).
4. **Closing-line value tracking** — log every bet vs close; CLV is the skill metric (*Sharper*, Buchdahl).
5. **Derivative lag** — main line moves, halves/props don’t (*Logic of Sports Betting*; Voulgaris lore).
